
# 나만의 용돈 기입장

Python으로 구현하는 콘솔 기반 가계부 프로그램입니다.

## 개발 환경
- Python 3.10 이상
- VS Code
- Python 표준 라이브러리

## 실행 방법

```bash
python3 -m budget_app --help
```

## 주요 기능 (개발 예정)
- 거래 추가 및 조회
- 거래 수정 및 삭제
- 거래 검색
- 월별 요약
- 예산 관리
- 카테고리 관리
- CSV 가져오기 및 내보내기

## 데이터 저장
- 저장 위치: ./data
- 저장 형식: JSONL (구현 예정)
